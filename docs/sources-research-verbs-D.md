| شجع | т.1 л.490, средняя колонка, низ | «(شَجُعَ) ـُ شَجاعةً: قَوِيَ قلبُه واشتدَّ عند البأس، فهو شَجِيعٌ» |

Оговорки: скан чёрно-белый, знаки мелкие; у ضخم знак над خ мелкий, прочитан вместе с маркером ـُ (и подтверждён вторым источником). Тексты shamela для Wasit почти без огласовок, поэтому огласовку брал только со скана. Для كثر первый глагол (كَثَرَهُ) найден при просмотре скана (поиск по тексту shamela по заголовку «(كثر)» его не нашёл, так как заголовок там с суффиксом «ـه»). Для остальных статей список форм I проверен и по скану, и по тексту shamela (искал заголовки «(корень)»). Для ظرف (ظَرَّ) ـُ ظَرًّا на той же странице относится к корню ظرر.
