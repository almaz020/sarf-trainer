## Цитаты «مختار الصحاح»

- علم (ص217): «وَعَلِمَ الشَّيْءَ بِالْكَسْرِ يَعْلَمُهُ (عِلْمًا) عَرَفَهُ»
- فهم (ص244): «(فَهِمَ) الشَّيْءَ بِالْكَسْرِ (فَهْمًا) وَ (فَهَامَةً) أَيْ عَلِمَهُ»
- شرب (ص163): «(شَرِبَ) الْمَاءَ وَغَيْرَهُ بِالْكَسْرِ (شُرْبًا)»
- حفظ (ص76): «(حَفِظَ) الشَّيْءَ بِالْكَسْرِ حِفْظًا حَرَسَهُ»
- فرح (ص236): «(فَرِحَ) بِهِ سُرَّ ... وَبَابُهُمْ طَرِبَ» (прямого «بالكسر» нет, но «بابهم طرب» означает тип فَعِلَ)

## Что нужно отметить отдельно

1. علم: статья в Васите открывается НЕ глаголом علِم, а первым стоит (عَلَمَهُ) ـُ «пометил» (R2 фатха), и только следующий (عَلِمَ) даёт «знать» (касра). Для базы подходит глагол عَلِمَ «знать», омоним عَلَمَ не вносится. Две огласовки R2 для одного значения «знать» нет. Решение о включении оставляю владельцу.
2. Для остальных четырёх первым в статье стоит именно глагол с касрой, вторых огласовок R2 в прошедшем нет.
3. Мудари по скану у всех пяти ـَ (يَفْعَلُ), как и ожидается для فَعِلَ.

## Что может быть неточно

- Разрешение скана низкое; касра везде один короткий штрих под буквой (в علم и فهم самые мелкие). Для علم, فهم, شرب, حفظ второй источник прямо говорит «بالكسر»; для فرح только «بابهم طرب» плюс огласованный заголовок.
- Номера листов PDF с 0 (если с 1, то +1).
- Год и издатель тиража скана не напечатаны (см. sources-research-verbs.md).
