# Исследование: «شذا العرف في فن الصرف» (аль-Хамляви), другие копии

Дата: 2026-10-01. Правило: только то, что реально видно на скане/странице. Файлы проекта не менялись. Все страницы ниже прочитаны глазами по сканам PDF с archive.org (OCR использовался только для поиска страницы), номера страниц взяты из колонтитула скана. Поле `verified` остаётся за владельцем.

ВАЖНО: в разных изданиях нумерация страниц разная. Один и тот же «تنبيه» про тринадцать лиц стоит на с. 52 в издании Мактабат ар-Рушд (shamela, прошлое исследование), на с. 46 в издании Дар аль-Фикр (Бейрут), на с. 43 в издании аль-Матба'а аль-Амирийя и на с. 38 в издании Хаджар Асси (Дар аль-Фикр аль-Араби). ## 2. Не найдено

- Правило «آخر الماضي يُبنى على الفتح» и его сукун перед تاء/نا/نون النسوة как общая формулировка: поиск по OCR E2 на «مبني/يبنى/البناء/على الفتح» не дал такого абзаца (проверены все 141 листов по тексту, не по картинке; возможны пропуски OCR).
- Правило написания алифа после واو الجماعة (نصروا): не найдено. «الألف الفارقة» встречается только на листе 39 PDF E2 (печатный номер не просматривался) в смысле алифа между نون الإناث и نون التوكيد, к нصروا не относится. В перечне نصروا показано, алиф есть, но правила о нём нет.
- «ألف بعد واو الجماعة», «تُكتب الألف» (поиск по OCR E2 и E1): не найдено.
- `no-sign-on-madd-letters` (отсутствие знака на буквах удлинения как правило): не найдено.
- `other-letters-vowelled`: не найдено, как и предполагалось (это орфографическое соглашение учебника).
- Правило об идгаме تاء الفاعل с نون النسوة (почему -تُنَّ с шаддой): нет. Книга лишь печатает «نصرتُنَّ» с шаддой в перечне; объяснения не найдено.
- Полная огласовка всех тринадцати форм в одном издании: нет ни в одном из найденных (E1 без огласовок, E2 и E3 с частичной).
- Номер издания и год для E2 (кроме прав 1420 г.х./2000 г.) и для E1 (кроме метаданных [1911]): не прочитаны на скане.
- Проверены только по OCR и не просматривались картинкой: другие записи archive.org (nono_463, Shada3rf), в них перечень не найден по OCR.

## 3. Что может быть неточно

- Огласовка в E2 и E3 на перечне частичная: полностью огласованы лишь نَصَرْتُ, نَصَرْنَ, نصرتُنَّ (шадда), нصرتْ (сукун), нصرتَا; остальное без знаков или со смещёнными знаками (в E2 над ر вместо ت). Рассматривайте это как типографскую неточность, не как правило книги.
- Для hum: «نصرُوا» (E2) с дammой на ر и алифом, в E3 «نصروا» без знаков. Знаки читал глазами по 300 dpi, но мелкие знаки могут быть прочитаны неверно.
- Печатный номер E3: OCR показал «۴۸», на скане видно «٣٨»; верен номер, виденный на скане (38).
- Лист PDF (позиция в файле) и печатная страница не совпадают; ниже печатные номера. Индексы листов: E1 лист 45, E2 лист 43, E3 лист 39 (счёт с 1).
- E1: год [1911] взят из метаданных библиотеки, не с титула. Совпадение текста с E2/E3 по этому перечню: состав форм одинаков.
- Сайт shamela (E0): с. 52. Не совпадает с E2/E3/E1 по нумерации, нужно указывать издание.
