## Итог

Для всех 8 глаголов `unambiguous = true`: под корнем найден ровно один глагол формы I (с огласовкой R2 как у внесённого в базу), второго глагола формы I с другой огласовкой R2 ни в «الوسيط», ни в «مختار الصحاح» нет (в отличие от ضرب / خرج / علم, كثر / قبح).

## Оговорки

- Скан чёрно-белый, низкого разрешения. Знак R2 над/под буквой хорошо читается у فتح، قتل، كتب (фатха), слабее у شرب، فرح، فهم، حفظ (касра, один короткий штрих). Для этих четырёх огласовка подтверждена прямым «بالكسر» в «مختار» (для فرح «بابهم طرب»). Решение о втором глаголе принималось по ЗАГОЛОВКАМ статьи (наличие/отсутствие второй (فَعِلَ)/(فَعُلَ)/(فَعَلَ) того же корня), и оно не зависит от разрешения знака.
- Текст «مختار» взят с shamela, а не со скана печатной страницы.
- Номера листов PDF считаются с 0; печатные номера страниц на скане совпадают с shamela (по колонтитулам из sources-research-verbs-A/B.md; для с.317 и с.775 колонтитулы «- ٣١٧ -» и «- ٧٧٥ -» видны на изображении).
- Флаг `verified` не менялся и не ставился.
