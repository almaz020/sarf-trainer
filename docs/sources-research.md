## 4. Не найдено

- شذا العرف: правило, что в نَصَرُوا после واو الجماعة стоит ألف فارقة без знака (орфографическое соглашение «no-sign-on-madd-letters»). В книге «الألف الفارقة» встречается только на с. 48 (id 47 на shamela) в другом смысле: как ألف между نون الإناث и نون التوكيد (لتنصرنان), к письму نصروا не относится.
- شذا العرف: правило `other-letters-vowelled` (остальные буквы огласованы, сукун на конце): не найдено как формулировка.
- شذا العرف: شадда в окончании -تُنَّ (نَصَرْتُنَّ) и идгам نون النسوة: форма ضربتنّ/نصرتنّ в книге не найдена (поиск по «تُنَّ», «تنّ», «ضَرَبْتُنَّ», «نَصَرْتُنَّ» по всем 185 страницам shamela).
- شذا العرف: прямое указание окончаний для hum (نَصَرُوا), hunna (نَصَرْنَ), anta, antum, anti, antunna с таблицей: не найдено (есть только общее «تنبيه» на с. 52, см. выше, с неполным перечнем).
- شذا العرف: правило `stem` (R1 фатха + R2 V2, одинаковая во всех формах): прямой формулировки не найдено.
- شذا العرف: данные об издании (год, номер издания): сайт их не показывает.
- Wright, «A Grammar of the Arabic Language»: раздел и страница с парадигмой перфекта не найдены. Скачан текст 3-го изд. (archive.org, grammarofarabic01casp), но OCR с транслитерацией не позволил надёжно найти § с формами перфекта; значения не вносятся.
- Hans Wehr и др. (сверка к словарю): не искалось.

## 5. Что может быть неточно

- Номера страниц и тома для المعجم الوسيط по shamela объявлены сайтом как соответствующие печатному изданию («ترقيم الكتاب موافق للمطبوع»); на сканах archive.org номера на полях совпали (925, 449, 784). Но shamela и scan архива разбиты на тома по-разному (см. нумерацию листов): том взят из заголовка shamela (ج1 для سمع, ج2 для نصر и كرم); на archive.org совпало (том 1 для سمع, том 2 для остальных).
- Огласовки R2 в электронном тексте shamela для всех трёх глаголов отсутствуют; подтверждение взято из скана печатного издания (archive.org) и прочитано по изображению. Для نصر дополнительно совпал OCR. Для سمع и كرم читалось только по изображению (OCR для них шумный), поэтому уверенность «средняя».
- Издание сканов на archive.org: метаданные говорят только «1972», издатель не указан; совпадение сканов с изданием shamela («Вторая, 1972») по самому изданию не проверялось, кроме совпадения номеров страниц и текста статей.
- «Номер листа» (например, 0379, 0238, 466) это номер файла в скане, а не печатная страница.
- شذا العرف: в тексте shamela перечень форм 2-го лица на с. 52 выглядит искажённым (возможна опечатка издания или сайта); использовать только после сверки с бумажным экземпляром. Год и номер издания сайт не сообщает, заполнять должен владелец.
- Примеры в книге иногда даны без огласовки (shamela показывает «نصرنا» без знаков): в `paradigm.json` огласовки должны браться из ТЗ, а не из этих цитат.

Сверка: Wright, vol. 1, 3rd ed. 1896, Table I, с. 298 (قَتَلَ, полная огласовка, шадда в -تُنَّ).
- `stem`: «شذا العرف», Хаджар Асси, с. 16 («التقسيم الثالث...», три баба по огласовке عين: مفتوحة / مكسورة / مضمومة); сверка Wright Table I.
- **Отступления от ТЗ п. 3 (основной источник = «شذا العرف»), нужно решение владельца:**

Сверка: Wright § 7 Rem. a, с. 11 («alif otiosum»; номер страницы по OCR-колонтитулу). Часть соглашения «без сукуна и знака на буквах удлинения» ни одним источником дословно не подтверждена.
