# Этап 3: ход тренировки и счётчик (сарф-тренажёр)

Источник требований: `TZ_sarf_trainer.md` (п. 8, «Ход тренировки» и «Проверка»; п. 12, этап 3). Здесь только решения по неоднозначностям и план. Всё, чего нет здесь и в ТЗ, не реализуется. Движок (`src/engine`), `TrainerScreen` и логика `builder.ts`, `attempt.ts` этапов 1 и 2 не меняются.

## Объём

Сессия: случайный проверенный глагол, по нему 9 заданий в порядке п. 4 (hum → nahnu), затем следующий случайный глагол, не тот же подряд (если глаголов больше одного). После верного ответа автопереход через 1 с, после показа правильной формы переход по «Дальше». Счётчик за сессию: верно с 1-й попытки / со 2-й / не решено. Между сессиями ничего не сохраняется. Сообщение «Нет проверенных глаголов в verbs.json» и гейт по ссылкам правил уже реализованы на этапе 2.

## Принятые решения

1. **Сессия бесконечная**, до перезагрузки страницы. Нет итогового экрана и кнопки «Завершить».
2. **Выбор глагола:** независимый случайный; единственное ограничение ТЗ: не тот же глагол подряд. Если глагол один, он повторяется. Первый глагол тоже случайный.
3. **Счётчик:** компактная строка над заданием: «С 1-й попытки: N · Со 2-й: N · Не решено: N». `data-testid="counter"`.
4. **Автопереход:** `ADVANCE_DELAY_MS = 1000`. Счётчик обновляется сразу, до перехода. Ссылка на правило видна всё время ожидания (ТЗ: «пока он на экране»). После показа правильной формы автоперехода нет, только «Дальше».
5. **Таймер** очищается при размонтировании `App`.
6. **Тестовая подстановка случайности:** `App` принимает необязательный `random: () => number` (по умолчанию `Math.random`).
7. **Данные для просмотра:** `demo.ts` получает ещё два TEST-глагола (по образцу سمع и كرم); `?demo` показывает все три. В продакшен-сборку они не попадают.

## Модули

`src/ui/session.ts` (чистая логика, TDD):

- `PRONOUN_ORDER: PronounId[]`: hum, hiya, hunna, anta, antum, anti, antunna, ana, nahnu.
- `Counter { first: number; second: number; failed: number }`, `emptyCounter`, `addResult(counter, result: AttemptResult): Counter`.
- `pickVerb(verbs: Verb[], previous: Verb | null, random: () => number): Verb`.
- `SessionState { verb: Verb; index: number; counter: Counter }`, `startSession(verbs, random)`, `nextTask(state, verbs, random)`, `currentPronoun(state)`.

`App` держит `SessionState` и номер задания (для `key`). `onResult` → `addResult`; на `first` и `second` ставится таймер на `nextTask`; `onNext` (после `failed`) вызывает `nextTask` сразу.

## Тесты

- `session.test.ts`: порядок 9 местоимений; после девятого новый глагол; не тот же подряд при ≥2 глаголах (контролируемый `random`); один глагол повторяется; счётчик.
- `App.test.tsx` (fake timers): до 1000 мс задание то же, правило видно, счётчик обновлён; через 1000 мс следующее местоимение; после `failed` автоперехода нет даже через 5 с; «Дальше» → следующее; счётчик копится между заданиями; смена глагола после 9-го задания; таймер не срабатывает после размонтирования.
- Визуально: `?demo`, смена заданий и глаголов, счётчик, 360 px.

## Вне этапа

Итоговый экран, «Завершить», хранение прогресса, «задание N из 9», перемешанный круг по глаголам.
