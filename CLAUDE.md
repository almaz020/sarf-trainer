# Правила проекта

- Единственный источник требований: TZ_sarf_trainer.md. Перед любой задачей сверяйся с ним.
- Не добавлять грамматических правил, форм, местоимений и функций, которых нет в ТЗ.
- Никогда не выдумывать номера страниц, изданий и ссылки на источники: эти поля заполняет владелец. Исключение (по указанию владельца): можно вносить только то, что реально найдено в интернете в источнике, с URL, откуда взято; что не найдено, остаётся пустым. Позже владелец поручил заполнить данные самому Claude: флаг `verified: true` ставится только если том, страница и огласовка подтверждены по найденным источникам (сканы/тексты), с пометкой в docs/sources-research.md; владелец сам данные не вписывает.
- Неоднозначность огласовки R2 (решение владельца, 2026-10-03, заменяет решение от 2026-10-02): если под корнем в основном словаре стоят несколько глаголов формы I с разной R2 (дَخَلَ «войти» / دَخِلَ «испортиться»), это РАЗНЫЕ глаголы; в `verbs.json` вносится основной (частотный) глагол, редкий отмечается в docs. Не вносится только глагол, у которого для ОДНОГО значения допустимы две огласовки R2 (напр. «بالفتح والكسر»), или если основной глагол не удаётся установить по источникам.
- При любой неоднозначности остановиться и задать вопрос, не додумывать.
- После изменений в src/engine обязательно запускать тесты (npm test) и показывать результат.
- Отвечать на русском.
